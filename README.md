# ETgram - MERN Stack Social App (Frontend)

This project is the frontend for a social media application built using the MERN stack.

## Technologies Used

*   React
*   Redux
*   Material-UI
*   CSS
*   React Router Dom

## Features

Based on common features of MERN stack social media apps, this frontend likely includes:

*   User Authentication (Sign Up, Login, Logout)
*   Viewing and creating posts
*   Liking and unliking posts
*   Following and unfollowing users
*   Viewing user profiles

## Getting Started

To get the frontend running locally:

1.  Clone the repository.
2.  Navigate to the project directory in your terminal.
3.  Install dependencies using yarn:

    ```bash
    yarn install
    ```

4.  Start the development server:

    ```bash
    yarn start
    ```

    The application should now be running at `http://localhost:3000`.
